### Hi, I'm Amer

Full-stack developer building production-style retail/business management systems - Spring Boot APIs paired with Angular front ends, end to end: auth, multi-tenant data, POS/inventory workflows, payments, and now rule-based "smart" features (demand prediction, anomaly detection, recommendations) built on real data without relying on a paid AI API.

#### Featured projects

- **[Zaki Supermarket](https://github.com/amer-rouby/zaki-supermarket-backend)** ([frontend](https://github.com/amer-rouby/zaki-supermarket-frontend)) - full retail management system: POS, inventory, purchasing, supplier management, customer credit, offline-first sync, and a 13-feature "Zaki AI" layer (stock-risk prediction, reorder/pricing recommendations, anomaly detection, a rule-based assistant, Egyptian e-invoice integration).
- **[SmartPharma](https://github.com/amer-rouby/smartpharma-backend)** ([frontend](https://github.com/amer-rouby/smartpharma-frontend) - [mobile](https://github.com/amer-rouby/smartpharma-mobile)) - multi-tenant pharmacy management system that Zaki Supermarket was later forked from.
- **[Sahm POS](https://github.com/amer-rouby/sahm-pos-api)** ([dashboard](https://github.com/amer-rouby/sahm-pos-dashboard)) - point-of-sale API and dashboard.
- **[Employee Management System](https://github.com/amer-rouby/Employees-management-backend)** - HR backend: employees, departments, leave requests, JWT auth.
